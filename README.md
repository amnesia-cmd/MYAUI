# Jarvis

A browser-based personal AI assistant prototype.

## Overview

This project combines a conversational interface, an Express backend, Claude-powered responses, and browser speech synthesis.

## Features

- Conversational interface
- Claude API integration
- Markdown responses
- Browser speech synthesis
- Express API backend

## Stack

- HTML, CSS, Vanilla JavaScript
- Node.js and Express
- Anthropic Claude
- Web Speech API

## Development

```bash
npm install
npm start
```

Configure the Anthropic API credential through a local `.env` file.

> Never commit API keys or other credentials.

## Status

Prototype / learning project.
